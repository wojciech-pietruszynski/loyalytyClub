# Projekt: System Programu Lojalnościowego (Loyalty App)

## 1. Rola i Cel
Jesteś Senior Fullstack Developerem. Twoim zadaniem jest zbudowanie od zera działającej aplikacji programu lojalnościowego. Aplikacja ma składać się z backendu w Spring Boot oraz frontendu w React + TypeScript. Całość ma być budowana jednym poleceniem Mavena, gdzie skompilowany frontend jest serwowany statycznie przez backend.

## 2. Stos Technologiczny
- **Backend:** Java 21, Spring Boot 3.x (Web, Data JPA).
- **Baza Danych:** PostgreSQL (uruchamiany via `docker-compose.yml`).
- **Zarządzanie zależnościami:** Maven.
- **Frontend:** React 18+, TypeScript, Vite.
- **Integracja Builda:** Użyj `frontend-maven-plugin` w `pom.xml`, aby zintegrować budowanie frontendu (npm install, npm run build) z cyklem życia Mavena i skopiować folder `dist` Vite'a do `target/classes/static` Springa.

## 3. Model Domenowy (Baza Danych)
Zaimplementuj encje z relacjami JPA:
1. **Customer:** `id`, `firstName`, `lastName`, `email`, `loyaltyPoints`.
2. **Transaction:** `id`, `customerId`, `points` (dodatnie/ujemne), `description`, `timestamp`.
3. **Reward:** `id`, `name`, `pointsCost`, `description`.

## 4. Wymagania Backendowe (API REST)
Utwórz warstwę REST API (`/api/...`) używając DTO i globalnej obsługi wyjątków (ControllerAdvice):
- GET /api/customers i POST /api/customers (zarządzanie klientami).
- GET /api/customers/{id} (pobieranie profilu i salda).
- POST /api/customers/{id}/add-points (dodawanie punktów, tworzy Transaction).
- POST /api/customers/{id}/redeem (wymiana na nagrodę, walidacja salda, tworzy Transaction).
- GET /api/rewards (lista nagród).

## 5. Wymagania Frontendowe (React + TS)
W głównym katalogu projektu utwórz folder `frontend` i zainicjalizuj w nim projekt Vite + React + TS.
- Użyj komponentów funkcyjnych i Hooków.
- Zbuduj interfejs z zakładkami/widokami: "Klienci", "Dodaj Punkty", "Nagrody".
- Zapewnij typowanie dla odpowiedzi z API (interfejsy TS odpowiadające DTO z backendu).
- Użyj `fetch` lub `axios` do komunikacji z API (żądania do `/api/...`).
- Zadbaj o prosty, schludny wygląd (możesz użyć czystego CSS, CSS Modules lub TailwindCSS - wybierz najszybszą dla Ciebie metodę).

## 6. Plan Wykonania (Krok po kroku)
Wykonaj poniższe kroki w podanej kolejności. Zawsze czekaj na moją akceptację przed przejściem do kolejnego:
1. **Inicjalizacja Backendu:** Wygeneruj strukturę Mavena, `pom.xml`, `application.yml` oraz `docker-compose.yml` dla PostgreSQL.
2. **Warstwa Danych:** Stwórz Encje, Repozytoria i Serwisy z logiką biznesową.
3. **Warstwa API:** Stwórz Kontrolery REST, klasy DTO oraz obsługę błędów.
4. **Inicjalizacja Frontendu:** Utwórz folder `frontend`, wygeneruj projekt Vite (React+TS) i skonfiguruj `vite.config.ts` (ustaw proxy dla `/api` na `http://localhost:8080` do dewelopmentu).
5. **Logika Frontendu:** Napisz komponenty Reactowe, interfejsy TypeScript i podepnij je pod REST API.
6. **Integracja Builda (Kluczowe):** Skonfiguruj `frontend-maven-plugin` oraz `maven-resources-plugin` w głównym `pom.xml`, aby polecenie `mvn clean install` budowało frontend i kopiowało wynik do katalogu static backendu.

**Zasady kodowania:**
- Utrzymuj czysty, modularny kod.
- Pisz kod w języku angielskim, ale komunikuj się ze mną po polsku.
- Unikaj "mockowania" na stałe - frontend ma realnie strzelać do backendu.
